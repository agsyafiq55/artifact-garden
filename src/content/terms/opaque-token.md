term: "Opaque token"
aka: [reference token]
definition: "A random token with no meaning of its own. The server looks it up in its own store on every request, so deleting it revokes it at once."
analogy: "A cloakroom ticket number that means nothing until staff look it up."
example: "We switched admin sessions to opaque tokens, so a ban takes effect on the very next request."
