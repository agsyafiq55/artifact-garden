---
term: "Scope"
aka: [OAuth scope]
definition: "A named permission an app asks for and the user approves, such as `photos.read`. An access token can do only what its scopes allow."
analogy: "The list of doors a hotel key card opens."
example: "The delete call failed with `403` and `insufficient_scope`, because the token only had `photos.read`."
related: [access-token, oauth-2]
contrasts: []
topic: security
