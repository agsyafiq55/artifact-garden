---
term: "Stateless protocol"
aka: [statelessness]
definition: "A protocol where the server keeps no memory of earlier requests, so each request carries everything the server needs. HTTP is one."
analogy: "A shop counter where the clerk forgets you after each sale, so you show your loyalty card every time."
example: "HTTP is stateless, so the browser sends its `Cookie` header with every request to stay logged in."
