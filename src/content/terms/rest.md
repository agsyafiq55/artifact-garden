---
term: "REST"
aka: [Representational State Transfer, RESTful]
definition: "An architectural style where an API exposes resources at URLs, and clients read and change them through one uniform set of HTTP methods."
analogy: "A library where every book has a shelf mark, and the desk offers the same few actions for every book."
example: "`DELETE /orders/7` is RESTful. `POST /deleteOrder?id=7` puts the action in the URL instead of the method."
related: [resource, representation, uniform-interface, hypermedia, stateless-protocol]
contrasts: []
topic: backend
tags: [http, api-design]
added: 2026-11-26
---
