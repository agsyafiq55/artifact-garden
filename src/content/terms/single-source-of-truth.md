---
term: "Single source of truth"
aka: [SSOT]
definition: "One place that holds the real copy of the data, which every client reads and writes through."
analogy: "The order board in a restaurant kitchen that every waiter checks, instead of each one keeping their own notes."
example: "Orders live only in the server's database. The web and mobile apps each fetch them, so both always show the same list."
related: [server]
contrasts: []
topic: systems-design
tags: [client-server, data]
