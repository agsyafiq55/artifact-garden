---
term: "Uniform interface"
aka: []
definition: "The REST rule that every resource is used through the same methods with fixed meanings: GET reads, POST creates, PUT replaces, PATCH changes, DELETE removes."
analogy: "Every door in a building opens with the same handle, so you never relearn how to enter a room."
example: "Adding `/invoices` needed no new verbs, because the uniform interface already covers create, read, update and delete."
related: [http-method, rest]
contrasts: []
topic: backend
tags: [http, api-design]
added: 2026-11-26
---
