term: "Start line"
aka: [request line, status line]
definition: "The first line of an HTTP message. A request's names the method, target and version. A response's names the version, status code and reason phrase."
analogy: "The first line of a letter that says who it is for and what it is about, before any details."
example: "`POST /orders HTTP/1.1` is a request line, and `HTTP/1.1 201 Created` is a status line."
